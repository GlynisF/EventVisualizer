# User Stories

***Sign Up*** ★<br> As a new user, I want to sign up for an account to plan events.

***Sign In*** ★<br> As a registered user, I want to log in to access services the site offers.

***View Events*** ★<br> As a logged-in user, I want to view details for my stored events.

***Edit Events*** ★<br>As a logged-in user, I want to edit details for my events.

***Add Event*** ★<br>As a logged-in user, I want to create a new event and store my plans.

***Delete Event*** ★<br>As a logged-in user, I want to have the option to delete events I have stored.

***Custom Field***<br>As a logged-in user, I want the ability for my plans to be efficient yet flexible. Expectations, 
necessities, details, and requirements are often very dependent on the event. I want the option to add custom fields 
so my plans can be designed specifically for an event.<br>

***Undo Plans***<br> As a logged-in user, I want to easily undo / remove any unwanted custom fields 
without loosing progress or having to start over.

***Ask for Confirmation***<br> As a logged-in user, If I'm editing my plans I don't want to risk loosing plans 
if I forget to save before leaving the page or mistakenly delete wanted plans.

***Edit Plans On the Fly***<br> As a logged-in user, I want to be able to make changes without leaving the page when 
viewing my events.

***About<br>*** As any user, I want to be able to learn more about the site + mission statement or find contact information
for inquiries.<br>

***Retrieve Credentials***<br> As a registered user, I want to be able to retrieve or change my password if it's no longer
stored, or I forget.
