# User Stories

***Sign Up*** ★<br> As a new user, I want to sign up for an account to plan events.

***Sign In*** ★<br> As a registered user, I want to log in to access services the site offers.

***View Events*** ★<br> As a signed-in user, I want to view details for my stored events.

***Edit Events*** ★<br>As a signed-in user, I want to edit details for my events.

***Add Event*** ★<br>As a signed-in user, I want to create a new event and store my plans.

***Delete Event*** ★<br>As a signed-in user, I want to have the option to delete events I have stored.

***About<br>*** As any user, I want to be able to learn more about the site + mission statement or find contact information
for inquiries.<br>
